# 象牙塔漫记

这里用于记录学习过程中形成的个人思考、疑问、心得与阶段性总结。

## 目录

- `00-随手记/`：暂时不知道放在哪里的想法。
- `10-数学与基础/`：数学、信号与系统等基础思考。
- `20-编程与计算机/`：编程、工具和计算机基础思考。
- `30-专业学习/`：数字图像处理、测绘等专业课思考。
- `40-跨领域思考/`：暂时跨越多个领域的主题。
- `90-模板/`：写作模板，只提供结构，不代写内容。

## 使用原则

1. 先写下来，再整理；一时无法分类就放入 `00-随手记/`。
2. 一篇笔记围绕一个主要问题，文件名尽量表达问题或结论。
3. 个人判断与资料摘录分开标明；引用资料时记录来源。
4. 不提交教材原文、大型数据、编译产物、密码或访问令牌。

## 最简单的更新流程

在 VS Code 的“源代码管理”页面中：

1. 查看本次修改；
2. 在消息框写一句本次修改说明；
3. 点击“提交”；
4. 点击“同步更改”。
